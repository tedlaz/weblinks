# weblinks

My web links: https://tedlaz.github.io/weblinks/

Για να προσθέσεις link: άνοιξε το `links.js` και πρόσθεσε μια γραμμή `{t: "Τίτλος", u: "https://..."}` στην κατάλληλη ενότητα (προαιρετικά `n: "σημείωση"`).
Νέα κατηγορία = νέο `{id, title, sections}` — εμφανίζεται αυτόματα στο μενού ως `index.html#id`. Το `group` σε μια ενότητα ξεκινά νέα υπο-επικεφαλίδα.
Οι νεκροί σύνδεσμοι ελέγχονται κάθε Δευτέρα από το `.github/workflows/links.yml` (ανοίγει issue).
